# Mounjaro sem Mitos — Ebook Interativo

Ebook web interativo sobre **tirzepatida (Mounjaro)**, construído com HTML5 + CSS3 + JavaScript vanilla, sem dependências de build.

## Conteúdo

- **14 capítulos** baseados em evidências (SURMOUNT-1/2/4/5, SURPASS-2/6, Vigitel 2025, IDF 2025)
- **Laboratório Interativo** com 7 ferramentas:
  1. Mapa corporal clicável (onde a tirzepatida age)
  2. Comparador de medicamentos (Mounjaro, Ozempic, Wegovy, Saxenda)
  3. Simulador de efeitos colaterais (frequência, manejo, sinais de alerta)
  4. Triagem médica interativa (8 perguntas)
  5. Quiz de conhecimento (15 perguntas)
  6. Diários locais de peso e sintomas (com gráfico)
  7. Simulador KwikPen (5 passos da aplicação)
- **Glossário** com busca (27 termos) e **referências científicas**
- Progresso de leitura gamificado, modo escuro/claro, responsivo

## Como abrir

Basta abrir `index.html` em qualquer navegador — não há etapa de build. Todos os dados (progresso, diários) ficam no armazenamento local do navegador.

## Aviso

Conteúdo exclusivamente educativo. Não constitui recomendação de tratamento, prescrição ou substituição de consulta médica.
